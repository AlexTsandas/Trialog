# Trialog

### Three voices. One conversation.

Trialog is a full-stack, real-time messaging platform that brings human communication and artificial intelligence into the same conversation.

Users can communicate through private and group chats, share media, make voice and video calls, and collaborate with a shared AI assistant directly inside their conversations.

Unlike traditional AI chat applications, Trialog allows multiple users to interact with the same AI assistant while maintaining shared conversation context.

> 🚧 **Status:** In development

## Features

- Real-time private and group messaging
- Voice and video calls
- File, photo, and link sharing
- Online status, typing indicators, and read receipts
- Shared AI assistant accessible through `@AI`
- Private AI conversations
- AI conversation history and memory using RAG
